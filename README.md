# Restaurant Manager

Sistema integral de gestión para restaurantes y negocios de comida: punto de venta (POS), mesas, cocina en tiempo real (KDS), caja, inventario con recetas, personal, configuración white-label y landing pública con pedidos en línea.

**Demo en vivo:** [restaurant-manager-demo.vercel.app](https://restaurant-manager-demo.vercel.app)
